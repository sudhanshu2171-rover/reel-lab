# Trend Radar roadmap

The product should continuously identify rising Instagram Reels formats, audio, memes, festivals and cultural moments; score trend velocity and saturation; match trends to the user's niche; and explain how to adapt rather than copy.

Signals: recent usage growth, creator adoption, engagement velocity, freshness, niche fit, regional relevance, and saturation.

Current example signals researched Sep 4 2026: Janmashtami/Krishna AI transformation content, Potential-Maxxing, Ring My Bell lifestyle format, Oh yeah? cinematic-walk format, and Flop-Core/failure-to-relatable.

Important: static GitHub Pages cannot securely fetch authorized Instagram insights or hold API secrets. Production requires a backend + authorized Instagram/Meta integration + trend data provider/search layer.
