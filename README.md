# Reel Lab

Mobile-ready starter for an Instagram Reel analysis dashboard.

## Current version
- Paste a Reel URL
- Generates a clearly labeled demo/fallback performance estimate
- Scores hook, retention, shareability, and comment potential
- Suggests improvements and a stronger opening hook

## Production roadmap
A real Instagram analyzer requires authorized Instagram/Meta access and a server-side analysis layer. This repo intentionally does not place secret API keys in browser code.
